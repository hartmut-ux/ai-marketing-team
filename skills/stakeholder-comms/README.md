# Stakeholder Comms

Creates stakeholder communications including investor updates, board reports, annual impact reports, and partner communications aligned with B Corp PSG standards. Use when user asks about investor relations, board communications, stakeholder reporting, impact reports, annual reports, or partner/supplier communications.

## Structure

```text
stakeholder-comms/
├── README.md
├── shared/
│   └── SKILL-CORE.md
├── .kimi/skills/stakeholder-comms/SKILL.md
├── .claude/skills/stakeholder-comms/SKILL.md
└── .codex/skills/stakeholder-comms/SKILL.md
```

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
