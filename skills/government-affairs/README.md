# Government Affairs

Manages government affairs, public policy communications, and collective action aligned with B Corp GACA standards. Creates policy position papers, advocacy communications, regulatory response documents, and transparent lobbying reports. Use when user asks about government relations, public policy, advocacy, lobbying, regulatory affairs, collective action, or political engagement transparency.

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
