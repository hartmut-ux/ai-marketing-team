# Marketing Ops

Marketing operations manager handling budget planning, financial reporting, meeting preparation and follow-up, vendor management, and administrative workflows for marketing and communications departments. Designed for SME leaders who need to minimize time spent on operational overhead.

## Structure

```text
marketing-ops/
├── README.md
├── shared/
│   └── SKILL-CORE.md
├── .kimi/skills/marketing-ops/SKILL.md
├── .claude/skills/marketing-ops/SKILL.md
└── .codex/skills/marketing-ops/SKILL.md
```

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
