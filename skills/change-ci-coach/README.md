# Change Ci Coach

Guides continuous improvement and change management for SMEs adopting AI. Applies Marginal Gains philosophy, Kaizen principles, and structured sprint methodologies to organizational transformation. Use when user asks about change management, continuous improvement, AI adoption strategy, team resistance, transformation roadmaps, or improvement sprints.

## Structure

```text
change-ci-coach/
├── README.md
├── shared/
│   └── SKILL-CORE.md
├── .kimi/skills/change-ci-coach/SKILL.md
├── .claude/skills/change-ci-coach/SKILL.md
└── .codex/skills/change-ci-coach/SKILL.md
```

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
