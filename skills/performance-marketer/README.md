# Performance Marketer

Creates ad copy, Google Ads RSA headlines, A/B test plans, and campaign analysis for SME performance marketing. Handles paid search, paid social, email campaigns, and SEO content. Use when user asks about ads, campaigns, Google Ads, paid media, SEO, conversion optimization, or marketing performance metrics.

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
