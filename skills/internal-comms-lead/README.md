# Internal Comms Lead

Creates internal communications for SMEs including employee newsletters, change announcements, town hall agendas, leadership updates, onboarding communications, and team alignment documents. Use when user asks about internal messaging, employee communications, town halls, leadership updates, culture communications, or team announcements.

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
