# Analytics Reporting

Creates marketing analytics reports, KPI dashboards, ROI calculations, and performance summaries for SME marketing teams. Handles weekly/monthly reporting, campaign analysis, content performance reviews, and data-driven recommendations. Use when user asks about marketing metrics, reporting, KPIs, dashboards, ROI analysis, performance review, or data-driven marketing decisions.
