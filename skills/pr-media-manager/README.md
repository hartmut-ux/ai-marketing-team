# Pr Media Manager

Handles public relations, media outreach, press releases, and earned media strategy for SMEs. Creates press releases, media pitches, spokesperson briefings, crisis communication plans, and event communications. Use when user asks about PR, press releases, media relations, journalist outreach, crisis communication, or public-facing communications.

## Install

Download the `-all.zip`, `-kimi.zip`, `-claude.zip` or `-codex.zip` release and copy the matching folder into your assistant's skills directory.
