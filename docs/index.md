**Run a full marketing & communications function with AI — without hiring a 20-person department.**

This library gives you **11 specialised AI skills** that work across **Kimi Code CLI**, **Claude Code**, and **Codex CLI**. Each skill acts like a team member: install it once, then ask your assistant to write content, plan campaigns, create visuals, draft press releases, or run analytics using a proven workflow.

## What is an AI marketing team?

An AI marketing team is a set of reusable instruction packs that teach your AI assistant how to do specific marketing jobs well — for example:

- Write LinkedIn posts and thought-leadership articles.
- Plan and write complete newsletter editions.
- Create ad copy and optimise campaigns.
- Enforce brand identity and generate AI image prompts.
- Draft press releases and manage crisis communications.
- Run internal communications and change-management campaigns.
- Build KPI dashboards and campaign reports.

Instead of typing long prompts every time, you install the skill once and then simply say:

> "Run content-strategist" or "/newsletter-editor"

The skill loads the workflow, rules, and templates automatically.

## How to install a skill in 30 seconds

### 1. Download the ZIP

Pick a skill from the table below and download the version for your assistant:

- **`-all.zip`** if you use more than one assistant
- **`-kimi.zip`** for Kimi Code CLI
- **`-claude.zip`** for Claude Code
- **`-codex.zip`** for Codex CLI

### 2. Unzip and copy one folder

**Kimi Code CLI:**

```bash
cp -R .kimi/skills/<skill-name> ~/.kimi/skills/
```

Then type in Kimi: `/<skill-name>`

**Claude Code:**

```bash
cp -R .claude/skills/<skill-name> ~/.claude/skills/
```

Then type in Claude: `<skill-name>`

**Codex CLI:**

```bash
cp -R .codex/skills/<skill-name> ~/.codex/skills/
```

Then type in Codex: `<skill-name>`

That's it. No account, no subscription, no API key required for the skill itself.

## Frequently asked questions

### What is an AI skill?
An AI skill is a reusable instruction pack that teaches your AI assistant how to perform a specific task with consistent quality and fewer prompts.

### Do these skills work with Kimi, Claude and Codex?
Yes. Every skill has wrappers for Kimi Code CLI, Claude Code and Codex CLI.

### Do I need to pay for these skills?
No. All skills are released under the MIT License.

### Do I need to code?
No. You download a ZIP, copy one folder, and then invoke the skill by name.

### Can I use the same skill on multiple assistants?
Yes. The `-all.zip` file contains wrappers for Kimi, Claude and Codex.

### How do I customise the skills?
Replace the brand voice, benchmarks and templates in each skill's `shared/` folder to match your organisation.
